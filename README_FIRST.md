# Scanlark Final SVG / Vector Asset Pack

This is the final Concept 1-only Scanlark asset pack.

The logo source of truth is the confirmed horizontal logo supplied by Connor:
a navy lark integrated with a bright-blue magnifying glass and the Scanlark
wordmark.

## Important

- Every primary logo variant in this pack is derived from the same traced master.
- The production SVG logos contain vector paths and gradients only.
- They do not embed the original PNG.
- No shield logo or alternative concept is included.
- The header, footer and email-signature images are reference mockups only.

## Quick installation

Copy:

`apps/web/public/brand/`

into:

`scanlark/apps/web/public/brand/`

Then copy:

`apps/web/public/site.webmanifest`

into:

`scanlark/apps/web/public/site.webmanifest`

The supplied React component can be adapted or copied from:

`apps/web/src/components/brand/ScanlarkLogo.tsx`
