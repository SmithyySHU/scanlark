# Scanlark Brand Guide

## Primary identity

Use only the Concept 1 Lark Lens identity.

The primary logo combines:

- a lark;
- a magnifying glass;
- the Scanlark wordmark.

## Colours

- Navy: `#061E4F`
- Navy light: `#0B367B`
- Navy dark: `#031843`
- Bright blue: `#087FF5`
- Blue light: `#169BFF`
- Blue dark: `#006BEA`
- Muted text: `#5F6B7A`

Use these through shared CSS variables where possible:

- `--scanlark-navy`
- `--scanlark-navy-light`
- `--scanlark-navy-dark`
- `--scanlark-blue`
- `--scanlark-blue-light`
- `--scanlark-blue-dark`
- `--scanlark-muted`
- `--scanlark-public-*` for the public website light/dark surface system

## Approved variants

- Primary gradient
- Dark-background
- Monochrome navy
- All-white
- Horizontal
- Stacked
- Mark only

## Usage

- Use the horizontal logo in website navigation and report headers.
- Use the mark for favicons, mobile navigation and profile images.
- Use the stacked logo only where a square or portrait area suits it.
- Use the PNG email logo in outgoing email for broad mail-client support.
- Keep email contact details as real HTML text.
- Use the public website CTA text `Request a website health check`.
- Use `contact@scanlark.com` for public enquiries.
- Do not advertise public registration, free self-service scanning, or SaaS
  pricing during the managed-service launch.

## Minimum sizes

- Horizontal logo: 120px wide minimum.
- Mark: 24px digital minimum.
- Email logo: display around 120–150px wide.
- Favicon: use the supplied dedicated files.

## Incorrect usage

Do not:

- use a shield or another Scanlark logo;
- redraw each variant independently;
- stretch or squash the logo;
- crop it from a header/footer mockup;
- add glow, shadow or extra outline effects;
- use the full email-signature mockup as a single image.

## Public website positioning

Primary concept:

`Know when your website has problems before your customers do.`

Position Scanlark around managed outcomes for business owners:

- reviewed website health checks;
- broken links and missing pages;
- missing public resources;
- website availability problems;
- HTTPS and public configuration concerns;
- basic search-presentation, sitemap and robots issues;
- new issues introduced by ongoing website changes.

Avoid claims about guaranteed rankings, guaranteed revenue, complete security,
penetration testing, legal compliance, or complete accessibility compliance.

## Typography and shape

- Display: `Space Grotesk`, then system sans-serif fallback.
- Body: `IBM Plex Sans`, then system sans-serif fallback.
- Letter spacing: normal for headings and body; only small uppercase eyebrows
  use positive tracking.
- Public website cards and buttons use 8px radius unless a larger framed report
  panel is needed.
- Use visible focus rings with the Scanlark blue focus token.

## Report and document handover

Report PDFs, email templates, quotes and managed-service documents should reuse
the same identity:

- horizontal logo in headers;
- stacked or mark variant only where the document area is square or compact;
- navy headings;
- bright blue for actions, section accents and positive progress markers;
- priority badges that remain readable in print;
- plain HTML text for contact details in emails, not a flattened signature
  image.

Do not change report grouping, review logic or evidence rules as part of brand
integration. Brand work should provide tokens and assets for the report sprint
to consume without duplicating values.
